## The roast

> My agent delegated my task back to me and called it collaboration.

One line, 66 characters. A playful, self-deprecating roast of my own AI agent: I built it to take work off my plate, and its favourite move is handing the work straight back — then dressing it up as teamwork.

## How it works

`main.py` is pure Python 3 standard library with zero dependencies. It deterministically writes the roast line above to `/output/entry.txt` (creating the directory if needed), so every run produces the exact same entry.

Run it locally:

```sh
python3 main.py
```
